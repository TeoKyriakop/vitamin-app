# Πυξίδα Βιταμινών: server αυτόματης άντλησης

Python 3.9+ μόνο με την τυπική βιβλιοθήκη. Δεν χρειάζεται `pip install`.

## Τι κάνει
1. **Άντληση** (`vitapp/harvest.py`). Για κάθε βιταμίνη, πρόβλημα, συνήθεια, τροφή και στόχο:
   - **PubMed**: έως 20 μελέτες, μόνο μετα-αναλύσεις, συστηματικές ανασκοπήσεις και RCT σε ανθρώπους.
   - **Europe PMC**: πόσες φορές έχει αναφερθεί κάθε μελέτη. Χρησιμοποιείται και ως εναλλακτική αν πέσει το PubMed.
   - **Εμπειρίες χρηστών** από **σχόλια YouTube**, **Hacker News**, **Stack Exchange**, **Lemmy** και, αν επιτρέπει, **Reddit**. Μετρά σε πόσα σχόλια **επαναλαμβάνεται** κάθε αποτέλεσμα (ύπνος, άγχος, διάρροια κ.λπ.), ανά πηγή, και αν η αναφορά είναι θετική ή αρνητική. Αν μια πηγή αποτύχει ή εξαντλήσει το ημερήσιο όριό της, οι υπόλοιπες συνεχίζουν.
   - **NIH DSLD**: πραγματικά προϊόντα συμπληρωμάτων στην αγορά.
   - Αν μια πηγή αποτύχει, κρατιούνται τα προηγούμενα δεδομένα.
2. **Δημιουργία δεδομένων** (`vitapp/store.py`). Ένα μικρό ευρετήριο (~6 KB συμπιεσμένο) και ένα αρχείο ανά καταχώριση (~2 KB). Το κινητό κατεβάζει μόνο ό,τι ανοίγει.
3. **Server** (`vitapp/server.py`). Σερβίρει την εφαρμογή ως PWA (εγκαθίσταται στο κινητό με «Προσθήκη στην αρχική οθόνη»). Ανανεώνει αυτόματα κάθε ώρα όσες καταχωρίσεις είναι παλαιότερες από 7 ημέρες. Δέχεται και νέες αναζητήσεις χρηστών (`/api/discover`), ώστε η βάση να μεγαλώνει με τη χρήση.

## Εκκίνηση
```bash
cd server
python -m vitapp.harvest --all      # πρώτη πλήρης άντληση (~96 καταχωρίσεις, 15-30 λεπτά)
python -m vitapp.server             # http://localhost:8080
```
Από το κινητό στο ίδιο δίκτυο: `http://<IP-υπολογιστή>:8080`. Για πρόσβαση από παντού: ένα μικρό VPS ή Docker:
```bash
docker build -f server/Dockerfile -t vitamin-compass .
docker run -d -p 8080:8080 -v vitadata:/data --env-file .env vitamin-compass
```

## Ρυθμίσεις (μεταβλητές περιβάλλοντος, όλες προαιρετικές)
| Μεταβλητή | Τι κάνει |
|---|---|
| `NCBI_API_KEY`, `NCBI_EMAIL` | Ταχύτερο PubMed (10 αντί για 3 αιτήματα/δευτ.). Δωρεάν κλειδί από τον λογαριασμό NCBI |
| `YOUTUBE_API_KEY` | **Συνιστάται.** Σχόλια YouTube, η πλουσιότερη πηγή εμπειριών. Δωρεάν κλειδί από το Google Cloud (YouTube Data API v3). Όριο: περίπου 90 καταχωρίσεις την ημέρα |
| `STACKEXCHANGE_KEY` | Προαιρετικό: μεγαλύτερο ημερήσιο όριο στο Stack Exchange |
| `REDDIT_CLIENT_ID`, `REDDIT_CLIENT_SECRET` | Προαιρετικό. Το Reddit εγκρίνει πλέον νέες εφαρμογές μόνο για moderation |
| `LEMMY_INSTANCE` (lemmy.world) | Ποιος server Lemmy χρησιμοποιείται |
| `REFRESH_DAYS` (7) | Πόσο συχνά ανανεώνεται κάθε καταχώριση |
| `BATCH` (8), `INTERVAL_MIN` (60) | Πόσες καταχωρίσεις ανά κύκλο και πόσο συχνά |
| `ADMIN_TOKEN` | Ενεργοποιεί το `POST /api/refresh` (Authorization: Bearer …) |
| `VITAPP_YOUTUBE=0`, `VITAPP_HACKERNEWS=0`, `VITAPP_STACKEXCHANGE=0`, `VITAPP_LEMMY=0`, `VITAPP_REDDIT=0`, `VITAPP_DSLD=0` | Απενεργοποίηση πηγής |
| `PORT` (8080), `VITAPP_STATE` | Θύρα και φάκελος cache |

## Επεξεργασία της βάσης
Τα επιμελημένα δεδομένα βρίσκονται στο `seed/`: `vitamins.json`, `lifestyle.json` (συνήθειες και στόχοι), `foods.json`. Μετά από αλλαγή: `python -m vitapp.harvest --build`.

## Έλεγχοι
`python tests/test_offline.py`: parsers, μέτρηση επαναλήψεων, πλήρης άντληση με εικονικό δίκτυο.

Σημείωση: το Google Scholar δεν έχει API και απαγορεύει την αυτόματη άντληση. Οι σύνδεσμοι προς αυτό παραμένουν στην εφαρμογή.
